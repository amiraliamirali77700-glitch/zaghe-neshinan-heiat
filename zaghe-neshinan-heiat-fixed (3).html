🔄 اتصال آنلاین و همگام‌سازی لحظه‌ای

آفلاین

برای اینکه ثبت مکان هر نفر روی گوشی بقیه هم دیده شود، این بخش را یک‌بار تنظیم کن. Project URL و Publishable/anon key را از Supabase کپی و در دو کادر زیر وارد کن.

فقط Publishable/anon key را وارد کن؛ کلید service_role/secret را هرگز داخل سایت قرار نده. بعد از اتصال، وضعیت باید «🟢 آنلاین و همگام» شود.
پس‌زمینه: تصویر هوایی کربلا از Wikimedia Commons، اثر «ازهر حمید»، با مجوز CC BY-SA 4.0. برای استفاده‌ی عمومی، شرایط مجوز و ذکر منبع را حفظ کنید.
نسخه‌ی این فایل دارای ثبت بازه «از–تا» است. برای همگام‌سازی واقعی بین گوشی‌های اعضا، باید Backend آنلاین متصل شود.
